# 📝 全能双文档联动提取神器 (Dual-Document Context Extractor)

这是一个基于 Python 和 Tkinter 开发的轻量级 Windows 桌面工具。它可以帮助用户在两个文档之间进行精准的“联动跨文件搜索与上下文提取”，非常适合日志分析、数据清洗、核对清单等办公场景。

## ✨ 核心功能

* **双模式动态提取**：
    * **模式 1 (单关键词提取)**：通过指定固定关键词，精准提取其前面或后面的 N 个字符。
    * **模式 2 (双关键词夹心提取)**：设定起始和结束关键词，精准抠出夹在中间的动态内容。
* **跨文档智能检索**：自动将文档A中提取到的内容作为新的“搜索词”，去文档B中进行批量检索。
* **纯净版上下文保存**：在文档B中找到目标后，可自定义保存该行内容的“前 N 行”与“后 N 行”，并输出为纯净无干扰的新文本文档。
* **智能去重**：自动对文档A中提取的重复搜索词进行去重处理，提升检索效率。
* **编码兼容**：内置多重编码安全读取机制 (`utf-8`, `gbk`, `utf-8-sig`)，告别乱码烦恼。

## 🛠️ 开发者指南 (从源码构建)

如果你想自己修改代码并重新打包，请按照以下步骤操作：

**1. 准备环境**
建议使用 Python 3.10+，并创建一个干净的虚拟环境：
```bash

conda activate build_env

**2. 安装打包依赖**

```bash
pip install pyinstaller

**3. 一键打包**
在代码所在目录执行以下命令：

```bash
pyinstaller -F -w extractor.py
打包完成后，独立的可执行文件将生成在 dist 目录下。
